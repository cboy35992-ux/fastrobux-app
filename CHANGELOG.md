# Changelog

## 16.2.0
- Added separate admin order portals for Covered Tax, Not Covered Tax, Instant Robux, and In-Game Gifting.
- Added method-specific processing instructions, facts, validation checklists, and mobile portal navigation.
- Added secure inline receipt preview and full-image viewing.
- Fixed protected proof images not loading because empty image `src` was detected incorrectly.
- Fixed customer real-time order updates using an undefined order variable.
- Added PNG, JPG, WEBP, and GIF receipt/proof support with safe inline headers.
- Expanded admin order search to display name, game name, and item name.
- Preserved existing hidden-admin, order, storage, payment, messaging, proof, and Clear Orders systems.
