# RSR Shop V16

Production-ready Node.js shop with a responsive customer dashboard and private admin portal.

## Deploy
1. Upload the project contents to your repository.
2. Configure all values shown in `.env.example` in Render.
3. Run `npm install`, then `npm start`.
4. Keep `ADMIN_KEY` private and set `ADMIN_PORTAL_PATH` to your hidden admin route.

Setup notes are in `docs/`.
